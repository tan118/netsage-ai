# NET-004

## Symptom
Traffic fails across a trunk after an EtherChannel/native-VLAN change.

## Topology
Two switches use an EtherChannel trunk with VLAN 150 as the intended native VLAN.

## Show Outputs
show etherchannel summary -> Port-channel is down; show interfaces trunk -> native VLAN mismatch.

## Expected Fault
Native VLAN configuration is inconsistent on the Port-channel/trunk.

## OSI Layer
Layer 2

## Concept
Native VLAN / EtherChannel

## Severity
High
