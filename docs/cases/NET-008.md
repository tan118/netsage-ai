# NET-008

## Symptom
PC can reach its gateway but remote hosts return unreachable.

## Topology
PC is in 192.168.30.0/24 and router interface is intended to be 192.168.30.1.

## Show Outputs
show ip interface brief -> gateway interface uses 192.168.40.1/24 instead of the VLAN 30 subnet.

## Expected Fault
Gateway interface address does not match the client subnet.

## OSI Layer
Layer 3

## Concept
Gateway subnet mismatch

## Severity
High
