# NET-001

## Symptom
PCs in the same VLAN cannot ping each other.

## Topology
PC-A and PC-B connect to the same access switch and should be in VLAN 10.

## Show Outputs
show vlan brief -> VLAN 10 exists; show interfaces switchport -> Fa0/2 is in VLAN 20.

## Expected Fault
Fa0/2 is assigned to the wrong VLAN.

## OSI Layer
Layer 2

## Concept
VLAN access-port assignment

## Severity
Medium
