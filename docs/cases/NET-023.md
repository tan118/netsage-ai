# NET-023

## Symptom
A server should be blocked from one subnet, but other traffic must continue working.

## Topology
R1 connects a client LAN and a protected server.

## Show Outputs
show access-lists -> ACL contains an overly broad deny entry.

## Expected Fault
ACL source/destination matching is too broad.

## OSI Layer
Layer 3/4

## Concept
ACL wildcard matching

## Severity
High
