# NET-017

## Symptom
Router can ping a remote network but a PC behind the router cannot.

## Topology
R2 has a static route to 192.168.3.0/24; PC is behind R2.

## Show Outputs
show ip route -> R2 has 192.168.3.0/24; PC gateway/configuration does not point to R2.

## Expected Fault
Host is using the wrong gateway.

## OSI Layer
Layer 3

## Concept
Static routing + host gateway

## Severity
High
