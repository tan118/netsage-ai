# NET-028

## Symptom
NAT is configured but some VLAN clients cannot reach the simulated Internet.

## Topology
R1 provides DHCP and NAT/PAT for multiple internal VLANs.

## Show Outputs
show access-lists -> NAT ACL does not include one internal subnet; show ip nat translations -> clients from that subnet have no translations.

## Expected Fault
NAT matching ACL excludes the affected subnet.

## OSI Layer
Layer 3

## Concept
NAT ACL

## Severity
High
