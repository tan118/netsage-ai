# NET-032

## Symptom
Laptop is configured for wireless but cannot communicate while wired PCs work normally.

## Topology
Small network has wired clients and a wireless router/AP.

## Show Outputs
Laptop IP/gateway appear correct; show interfaces/route evidence points to wireless VLAN or AP uplink not carrying the expected network.

## Expected Fault
Wireless access/uplink VLAN configuration is incorrect.

## OSI Layer
Layer 2/3

## Concept
Wireless VLAN/uplink

## Severity
Medium
