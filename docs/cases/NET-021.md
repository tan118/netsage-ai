# NET-021

## Symptom
VLAN 30 should access VLAN 10, but after applying an ACL all connectivity breaks.

## Topology
Multilayer switch routes between VLAN 10 and VLAN 30.

## Show Outputs
show access-lists -> deny rule matches unintended traffic; interface ACL is applied in the wrong direction.

## Expected Fault
ACL rule/order or direction is incorrect.

## OSI Layer
Layer 3/4

## Concept
Extended ACL

## Severity
High
