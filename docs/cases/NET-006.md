# NET-006

## Symptom
PC can ping local devices but cannot reach another subnet.

## Topology
PC and gateway are on the same LAN.

## Show Outputs
show ip interface brief -> router LAN interface 192.168.20.1/24; PC gateway is 192.168.20.1; expected fault is a different subnet mask on the PC.

## Expected Fault
Incorrect host subnet mask prevents correct remote-network forwarding.

## OSI Layer
Layer 3

## Concept
Subnet mask / gateway relationship

## Severity
High
