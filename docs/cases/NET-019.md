# NET-019

## Symptom
Two PCs on different routed networks cannot communicate.

## Topology
R1 and R2 are connected by a routed link.

## Show Outputs
show ip route -> each router lacks a route to the remote LAN.

## Expected Fault
Remote LAN routes are missing.

## OSI Layer
Layer 3

## Concept
Routing table

## Severity
High
