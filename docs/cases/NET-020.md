# NET-020

## Symptom
All wired clients communicate, but a wireless client cannot reach an internal destination.

## Topology
Network has inter-VLAN routing and a wireless segment.

## Show Outputs
show ip route -> wireless subnet is missing from the routing table; client IP/gateway are otherwise correct.

## Expected Fault
Route to the wireless/client subnet is missing.

## OSI Layer
Layer 3

## Concept
Static/dynamic routing

## Severity
High
