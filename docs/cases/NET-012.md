# NET-012

## Symptom
Branch client cannot obtain DHCP from a central server.

## Topology
Branch VLAN is routed to HQ where the DHCP server resides.

## Show Outputs
show running-config interface vlan 20 -> missing ip helper-address; show ip route -> HQ route exists.

## Expected Fault
DHCP relay is missing even though routing works.

## OSI Layer
Layer 3

## Concept
Centralized DHCP

## Severity
High
