# NET-007

## Symptom
Wireless laptop has a correct-looking IP but cannot reach the rest of the network.

## Topology
Wireless router/AP connects clients to an enterprise VLAN and upstream gateway.

## Show Outputs
show ip route -> upstream route exists; laptop IP configuration -> default gateway points to the wireless router instead of the intended enterprise gateway.

## Expected Fault
Incorrect default gateway on the wireless client.

## OSI Layer
Layer 3

## Concept
Default gateway

## Severity
Medium
