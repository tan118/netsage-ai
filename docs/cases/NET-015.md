# NET-015

## Symptom
DNS and HTTP fail after an ACL is applied.

## Topology
Internal clients access DNS and web services through a router ACL.

## Show Outputs
show access-lists -> DNS/HTTP traffic is denied by an ACL entry.

## Expected Fault
ACL is blocking DNS/HTTP traffic.

## OSI Layer
Layer 4/7

## Concept
ACL service filtering

## Severity
High
