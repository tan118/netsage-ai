# NET-029

## Symptom
Laptop receives an IP and gateway but cannot reach internal hosts.

## Topology
Wireless router/AP connects a laptop to an enterprise VLAN.

## Show Outputs
show ip route -> wireless subnet is not routed correctly; wired clients work.

## Expected Fault
Wireless subnet routing is missing/incorrect.

## OSI Layer
Layer 3

## Concept
Wireless routing

## Severity
High
