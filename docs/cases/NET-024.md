# NET-024

## Symptom
Guest VLAN should reach the DMZ web server but cannot ping the gateway or access HTTP.

## Topology
Guest VLAN 60 and DMZ VLAN 30 are routed through a multilayer device.

## Show Outputs
show access-lists -> guest traffic is denied; show interfaces -> SVI/trunk state must also be checked.

## Expected Fault
ACL is blocking guest traffic, potentially combined with a Layer-2 issue.

## OSI Layer
Layer 3/4

## Concept
Guest isolation ACL

## Severity
High
