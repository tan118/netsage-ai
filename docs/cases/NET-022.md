# NET-022

## Symptom
DNS/HTTP works without ACL but fails when ACL is enabled.

## Topology
Internal network accesses DNS and web services through a router.

## Show Outputs
show access-lists -> required UDP/TCP traffic is denied.

## Expected Fault
ACL does not permit required application traffic.

## OSI Layer
Layer 4

## Concept
ACL service filtering

## Severity
High
