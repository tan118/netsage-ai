# NET-016

## Symptom
Client can ping the DNS server but browser cannot resolve the configured domain.

## Topology
DNS server is reachable from the client subnet.

## Show Outputs
nslookup/lookup test fails; DNS service is not enabled or configured for the requested record.

## Expected Fault
DNS service/record configuration is incomplete.

## OSI Layer
Layer 7

## Concept
DNS service

## Severity
Medium
