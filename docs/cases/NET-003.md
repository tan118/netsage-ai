# NET-003

## Symptom
A host in one VLAN cannot reach a host in another VLAN.

## Topology
Two VLANs exist on an L2 switch; no Layer-3 device is providing inter-VLAN routing.

## Show Outputs
show vlan brief -> VLANs exist; show ip route -> no routes/SVIs for the VLANs.

## Expected Fault
Inter-VLAN routing is missing.

## OSI Layer
Layer 3

## Concept
Inter-VLAN routing

## Severity
High
