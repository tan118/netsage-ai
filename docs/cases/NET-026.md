# NET-026

## Symptom
Internal clients cannot access the public web server.

## Topology
Enterprise LANs connect to an ISP router; NAT/PAT should translate private clients.

## Show Outputs
show ip nat translations -> no entries after a test connection; show ip interface -> outside interface is not marked ip nat outside.

## Expected Fault
NAT outside interface is not configured correctly.

## OSI Layer
Layer 3

## Concept
NAT/PAT

## Severity
High
