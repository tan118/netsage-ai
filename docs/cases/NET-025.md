# NET-025

## Symptom
Private host cannot reach the simulated public server through NAT.

## Topology
Inside LAN uses 192.168.11.0/24; outside interface connects to simulated ISP.

## Show Outputs
show ip nat translations -> no translations appear; show running-config -> NAT inside/outside roles are missing or wrong.

## Expected Fault
NAT inside/outside interface roles are misconfigured.

## OSI Layer
Layer 3

## Concept
NAT/PAT

## Severity
High
