# NET-031

## Symptom
Wireless guest can reach internal server even though guest isolation is required.

## Topology
Guest VLAN 60 should be restricted from internal VLANs.

## Show Outputs
show access-lists -> no deny rule for guest-to-internal traffic.

## Expected Fault
Guest isolation/security ACL is missing or incorrect.

## OSI Layer
Layer 3/4

## Concept
Guest network isolation

## Severity
High
