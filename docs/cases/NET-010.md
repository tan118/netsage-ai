# NET-010

## Symptom
Client cannot obtain an address from the remote DHCP server.

## Topology
Client VLAN has an SVI and can ping the DHCP server using a static IP.

## Show Outputs
show ip interface brief -> SVI up; show running-config interface vlan 20 -> helper points to the wrong DHCP-server IP.

## Expected Fault
DHCP relay points to the wrong server address.

## OSI Layer
Layer 3

## Concept
DHCP relay

## Severity
High
