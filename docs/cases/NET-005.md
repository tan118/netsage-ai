# NET-005

## Symptom
A PC has an IP address but cannot reach a remote network.

## Topology
PC is connected to an access switch; router provides the default gateway.

## Show Outputs
PC IP configuration -> gateway is 192.168.10.254; router interface is 192.168.10.1.

## Expected Fault
PC has the wrong default gateway.

## OSI Layer
Layer 3

## Concept
Default gateway

## Severity
High
