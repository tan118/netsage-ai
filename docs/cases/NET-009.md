# NET-009

## Symptom
A host receives an APIPA address instead of a DHCP address.

## Topology
DHCP server is in VLAN 90; client is in VLAN 20; routing and trunks are present.

## Show Outputs
show running-config interface vlan 20 -> no ip helper-address is configured.

## Expected Fault
DHCP relay is missing on the client VLAN interface.

## OSI Layer
Layer 3

## Concept
DHCP relay

## Severity
High
