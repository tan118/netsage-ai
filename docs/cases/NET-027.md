# NET-027

## Symptom
Static NAT configuration for a whole network is rejected in Packet Tracer.

## Topology
Private network should map to a public range in a lab.

## Show Outputs
show running-config -> attempted network static NAT command is unsupported in Packet Tracer.

## Expected Fault
The proposed NAT method is not supported by the simulator; use supported NAT pool/PAT design.

## OSI Layer
Layer 3

## Concept
Static NAT limitations

## Severity
Medium
